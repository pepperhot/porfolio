BOT TELEGRAM: GENERATEUR TIKTOK

Objectif : Automatisation complète de création de contenu viral (Karaoké & Lyrics) depuis Telegram via IA

💡 Fonctionnalités Clés :

  • Mode Lyrics : Scraping de paroles & pochettes, génération d'images stylisées via Pillow.
  • Mode Karaoké : Téléchargement YouTube, extraction audio, transcription IA via OpenAI Whisper, rendu vidéo via MoviePy.
  • UX/UI : Interface Telegram interactive, personnalisation des polices et thèmes.

Guide d'utilisation du Bot Telegram

  • Commande /start pour initialiser
  • Mode Lyrics: envoyez "Artiste:Chanson"
  • Mode Karaoké: envoyez un lien YouTube

YHACK: PLATEFORME D'AUDIT DE SÉCURITÉ

Description : Scanner de vulnérabilités web automatisé (DAST) capable d'auditer la sécurité des sites en temps réel.

🛡️ Modules d'Attaque :

  • Injection SQL : Fuzzing paramétrique et détection d'erreurs SGBD.
  • XSS & RCE : Payloads polyglottes pour tester la réflexion.
  • SSTI : Injection de templates via Puppeteer.
  • Brute-Force : Attaque dictionnaire intelligente.
  • Reconnaissance : Scan de ports et énumération.

Workflow d'audit

  • 1. Entrez l'URL cible
  • 2. Sélectionnez les modules d'attaque
  • 3. Analysez les résultats

PROJECT MATRIX : RPG GO 2D

Description : Jeu de combat et de gestion en 2D développé en Go avec Ebiten.

🎮 Gameplay :

  • Exploration : Navigation via carte interactive.
  • Dojo & Forge : Zone d'entraînement et boutique.
  • Combat : Système au tour par tour basé sur Pierre-Papier-Ciseaux évoluté.
  • Consommables : Pilules Rouges et Bleues pour stratégie.

Architecture Technique :

  • Machine à États pour gestion des scènes
  • Moteur Ebiten pour rendu graphique
  • Logique IA avec choix pondérés
  • Système monétaire persistant
